### 5.7 闭环：从刷到一条笔记，到它变成你的资产

```
① 发现      在小红书刷到一条想抄的笔记
              ↓  右下角浮出「收藏到红笺」
② 收藏      注入层面板：归类默认选中上次用的位置，批注可以留空，标签可以后补
              ↓  一次点击
③ 落地      树里多一个节点 · 这个标签页的标题被改写 · Toast「已收藏到 串珠领域 / 做手链的」
              ↓
④ 速览      侧边栏：树 + 最近收藏，一眼知道自己开了哪些页面、分别属于谁
              ↓  点一条笔记
⑤ 深读      阅读器：像网页一样读（左边图右边文），就地写批注，左方向键右方向键翻页
              ↓  发现归得不对
⑥ 整理      管理页：拖拽归位、重命名、加标签、批量移动、删除
              ↓
⑦ 带走      导出 JSON / Markdown，给不装插件的同事
```

**每一环都在为「快」做设计**，这是这个工具的全部价值主张：

| 环节 | 没有工具时 | 红笺的做法 |
|---|---|---|
| 收藏 | 打开红笺 → 找目录 → 建节点 → 粘贴链接 | **在小红书页上点一下**，目录已经帮你选好了 |
| 归类 | 每次从树根一层层点下去 | 默认选中**上次用的位置**，四个方向一眼可选 |
| 写批注 | 切到别的软件去记 | 就在笔记旁边写，⌘↵ 保存 |
| 找东西 | 在几十个标签页里翻标题 | ⌘K 搜账号名、笔记标题、正文、批注 |
| 翻阅 | 一条一条点开 | ← → 上一条下一条，不用回到列表 |
| 批量整理 | 一个一个改 | ⌘ 多选 → 浮动批量条 |
| 加标签 | 每次手打 | 常用标签点一下就中，新标签存下来下次还在 |
| 回顾 | 忘了收藏过什么 | 「最近收藏」卡片 + 「全部收藏」视图 + 导出 |

### 5.8 这一版补齐的 UI 清单

| 界面 | 原型文件 | 里面有什么 |
|---|---|---|
| **小红书页内注入层** | `prototype/inject.html` | 右下角「收藏到红笺」浮动按钮、展开后的收藏面板（归类树 + 批注 + 标签）、作者旁的「收藏这个账号」按钮 |
| **弹窗与菜单** | `prototype/dialogs.html` | 新建分类、删除确认（要打名字才可删）、标签选择、批量操作条、树的右键菜单、导入、设置、反馈提示、快捷键一览 |

这两块是**闭环的缺口**：没有注入层，「收藏」就得离开小红书；没有弹窗，「管理」就只能靠右键硬凑。
